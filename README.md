# Conectados na Verdade

Site estático em HTML, CSS e JavaScript puro.

## Como abrir

Abra o arquivo `index.html` no navegador.

## Onde colocar os arquivos reais

- Imagem principal: `assets/img/home-bg.png`
- Áudio de boas-vindas: `assets/audio/boas-vindas.mp3`
- Outras imagens: `assets/img/`

## Publicação

Pode ser publicado em qualquer hospedagem estática: GitHub Pages, Netlify, Cloudflare Pages, Vercel estático, Apache ou Nginx.
